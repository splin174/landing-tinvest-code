# Т-Инвест: все портфели в Google Таблице и Telegram-боте — лендинг

Одностраничный лендинг цифрового продукта (инструкция за 1 200 ₽): как собрать все счета Т-Инвестиций в одной Google Таблице, которая обновляется сама, и получать утренний отчёт в Telegram.

Статика без сборки и зависимостей: `index.html` + `styles.css` + `script.js` + папка `images/`.

## Как открыть

- Локально: дважды кликнуть `index.html` (откроется в браузере).
- Или через локальный сервер: `python -m http.server 8000` → http://localhost:8000
- Онлайн: GitHub Pages (ветка `main`, корень).

## Структура

```
index.html     — разметка: шапка + 9 блоков; блок 4 «Продукт» = 4.1 «Что получаю?» (+ аккордеон «Что в инструкции?»), 4.2 «Как запустить автоматизацию?» (+ аккордеон «Техническая логика работы»); блок 6 «Безопасность и гарантия» (номера — в HTML-комментариях)
styles.css     — стили, mobile-first (480 / 768 / 1200px), переменные в :root
script.js      — ссылка на оплату, FAQ, карусель, лайтбокс, окно документов, cookie и Метрика, плавный скролл, анимации
oferta.html    — публичная оферта (собирается из docs-src/oferta-text.md)
privacy.html   — политика конфиденциальности (собирается из docs-src/privacy-text.md)
docs-src/      — тексты оферты и политики в Markdown
tools/build_docs.py — сборка oferta.html и privacy.html
tools/deploy.sh — выкладка на хостинг Sprinthost
images/        — скриншоты, логотип, оптимизированные копии (webp/jpg/mp4)
```

## Как поменять цену

Цена (сейчас 1 200 ₽) указана в `index.html` в двух местах — рядом с кнопками покупки в hero и в финальном блоке `#cta`:

```html
<span class="price__value">1&nbsp;200&nbsp;₽</span>
```

Поменяйте число в обоих местах (ищите по `price__value`). Между тысячами и сотнями и перед «₽» ставьте `&nbsp;`, чтобы цена не разрывалась.
Подпись под ценой («разовая оплата, без абонентской платы») — в соседнем `price__note`.
В `<title>`, meta-тегах, на кнопках и в `script.js` цены нет — там ничего менять не нужно.

## Как поменять ссылку на оплату

В `script.js`:

```js
const PAYMENT_URL = 'https://...';
```

Ссылка подставится в главную кнопку финального блока (`data-pay`) и откроется в новой вкладке. Пока значение пустое, кнопка ведёт к блоку `#cta`.
Кнопки в шапке и hero скроллят к финальному блоку. Если они тоже должны сразу вести на оплату, добавьте им атрибут `data-pay`.

## Выкладка на хостинг (Sprinthost)

Сайт: `t-invest.boxguide.ru` — поддомен сайта `boxguide.ru`, корень — `~/domains/boxguide.ru/public_html/t-invest` на сервере `splin74.xsph.ru`.

**Важно:** папка `t-invest` лежит внутри корня `boxguide.ru`. При выкладках на `boxguide.ru` её нельзя удалять или перезаписывать (никаких `rsync --delete` и очистки `public_html` без исключения `t-invest/`). Подробнее — в комментарии в начале `tools/deploy.sh`.

Выложить свежую версию из GitHub (в Git Bash, из корня проекта):

```
bash tools/deploy.sh
```

Скрипт скачивает ветку `main` из GitHub (поэтому сначала сделайте `git push`), делает на сервере бэкап текущего сайта в `~/backup_<дата-время>/t-invest`, выкладывает `index.html`, `oferta.html`, `privacy.html`, `styles.css`, `script.js`, `images/` и `.htaccess` и проверяет, что страницы открываются.
Файлы перезаписываются, но ничего не удаляется: файл, убранный из репозитория, на сервере нужно удалить вручную. Старые бэкапы тоже удаляются вручную.

`.htaccess` в корне репозитория — 301-редиректы с `www.t-invest.boxguide.ru` и с `boxguide.ru/t-invest/` на `https://t-invest.boxguide.ru/`. На GitHub Pages он не действует.

Для входа нужен ключ `~/.ssh/sprinthost_ed25519` и алиас `sprint` в `~/.ssh/config` (проверка: `ssh sprint pwd` — без запроса пароля).

## Оферта и политика конфиденциальности

`oferta.html` и `privacy.html` собираются из `docs-src/oferta-text.md` и `docs-src/privacy-text.md`. Руками HTML не правьте — изменения пропадут при следующей сборке.

1. Поправьте текст в `docs-src/oferta-text.md` или `docs-src/privacy-text.md`.
2. Из корня проекта выполните:

   ```
   python tools/build_docs.py
   ```

   Скрипт пересоберёт обе страницы и напишет, сколько жёлтых мест осталось.
3. Закоммитьте вместе `.md` и пересобранные `oferta.html` и `privacy.html`.

Разметка `.md`: `# ` — заголовок документа, `## ` — раздел, `1.1. …` — пункт, несколько строк подряд без пустой строки — блок реквизитов. Места в `[квадратных скобках]` подсвечиваются жёлтым. Адрес сайта задан константой `SITE` в `tools/build_docs.py` и тоже подсвечивается — после переезда на новый домен поменяйте его там и в `.md`. Подвал страниц берётся из `index.html`, поэтому после правки подвала на главной документы тоже нужно пересобрать.

## Яндекс Метрика и cookie

- **Номер счётчика** — `113395885`, константа `METRIKA_ID` в начале `script.js`. Если её очистить, счётчик не загружается.
  Включены Вебвизор, карта кликов и точный показатель отказов (`webvisor`, `clickmap`, `accurateTrackBounce`, `trackLinks`).
  Готовый код счётчика из интерфейса Метрики на страницу не вставляется: он загружается без согласия.
  Нет и блока `<noscript>` с картинкой — он тоже отправлял бы данные без согласия.
- **Согласие.** При первом посещении внизу экрана появляется плашка с кнопками «Принять» и «Отказаться».
  До нажатия «Принять» скрипт Метрики не подключается и запросов к `mc.yandex.ru` нет.
  Выбор хранится в `localStorage` под ключом `cookieConsent` (`accepted` / `declined`), после него плашка не показывается.
  При «Отказаться» Метрика не загружается никогда. Чтобы снова увидеть плашку, удалите этот ключ в браузере.
- Плашка и счётчик подключаются из `script.js` на всех трёх страницах: `index.html`, `oferta.html`, `privacy.html`.
- **Цели** отправляются через `ym(113395885, 'reachGoal', …)` и только если Метрика загружена после согласия.
  В интерфейсе Метрики создайте их так: Настройки счётчика → Цели → Добавить цель → тип «JavaScript-событие»,
  идентификатор — ровно как в таблице.

  | Идентификатор | Когда срабатывает |
  |---|---|
  | `buy_click` | клик по кнопке «Купить это решение сейчас» (любой элемент с `data-pay`) |
  | `cta_view` | финальный CTA (блок 8) показался на экране — один раз за визит |
  | `doc_open` | открытие оферты или политики во всплывающем окне |
  | `faq_open` | раскрытие любого вопроса в блоке 7 «Частые вопросы» |
- **Адрес сайта** — `https://t-invest.boxguide.ru/`. Он же должен стоять в интерфейсе Метрики (Настройки счётчика → Адрес сайта),
  иначе статистика собираться не будет. При смене домена адрес меняется там, в `docs-src/oferta-text.md` / `docs-src/privacy-text.md`,
  в константе `SITE` в `tools/build_docs.py` и в мета-тегах `og:url`, `og:image`, `twitter:image`.
