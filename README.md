# Т-Инвест: все портфели в Google Таблице и Telegram-боте — лендинг

Одностраничный лендинг цифрового продукта (гайд за 990 ₽): как собрать все счета Т-Инвестиций в одной Google Таблице, которая обновляется сама, и получать утренний отчёт в Telegram.

Статика без сборки и зависимостей: `index.html` + `styles.css` + `script.js` + папка `images/`.

## Как открыть

- Локально: дважды кликнуть `index.html` (откроется в браузере).
- Или через локальный сервер: `python -m http.server 8000` → http://localhost:8000
- Онлайн: GitHub Pages (ветка `main`, корень).

## Структура

```
index.html     — разметка, 16 блоков по ТЗ
styles.css     — стили, mobile-first (480 / 768 / 1200px), переменные в :root
script.js      — счётчик мест, ссылка на оплату, FAQ, карусель, плавный скролл, анимации
images/        — скриншоты, логотип, оптимизированные копии (webp/jpg/mp4)
```

## Как заменить скриншоты

Положите новый файл в `images/` и поменяйте `src` (и `width`/`height`) у нужного `<img>` в `index.html`.
Проще всего сохранить файл под тем же именем — тогда HTML менять не нужно.

| Файл | Где на странице |
|---|---|
| `1table.png` | Hero — лист «Итого» |
| `8total_tg.png` | «Проблема не в тебе» — команда /total |
| `11files.png`, `4template.png`, `12autoloading.png` | «Как это работает» — карусель: папка программы, шаблон таблицы, автозагрузка |
| `7guide1.png` | «Безопасно ли это» — токен «Только просмотр» (временно, вместо `screen-6-token.png`) |
| `4template.png` | «Один час — и навсегда» — пустой шаблон |
| `4template.png`, `2total.png` | «Что внутри» — карусель: шаблон таблицы и утренний отчёт |
| `3checkbox.png`, `10update.png` | «Что внутри» — «Обновить сейчас» |
| `5rub.png` | «Что внутри» — команда /rub |
| `7guide1–4.png` | «Что внутри» — карусель страниц гайда |
| `7guide_scroll.mp4` + `7guide_scroll-poster.jpg` | «Что внутри» — предпросмотр гайда (грузится по кнопке) |
| `logo.webp`, `favicon.png` | Шапка, финальный CTA, иконка вкладки |
| `og-image.jpg` | Превью при репосте (Open Graph) |

Если картинка не загрузится, вместо неё показывается серый блок с подписью из атрибута `data-alt`.

Видео-предпросмотр `images/7guide_scroll.mp4` собрано из исходного GIF `images/7guide_scroll.gif`.
Исходный GIF (~8 МБ) хранится только локально и в репозиторий не входит (см. `.gitignore`),
как и оригиналы логотипов `images/logo.png` и `images/logo2.png`.
Если GIF есть у вас на диске и вы его обновили — пересоберите mp4:

```
ffmpeg -i images/7guide_scroll.gif -movflags +faststart -pix_fmt yuv420p -vf "scale=trunc(iw/2)*2:trunc(ih/2)*2" -c:v libx264 -crf 26 images/7guide_scroll.mp4
```

## Как поменять цены

В `index.html`, блок `#price`: элементы с атрибутами `data-price-1`, `data-price-2`, `data-price-3`.
Цена 990 ₽ также написана на кнопках (шапка, hero, финальный CTA), в блоке «Почему так недорого», в `<title>` — ищите по «990».

## Как поменять счётчик мест

Первая строка `script.js`:

```js
const seatsLeft = 47;
```

Склонение («место / места / мест») и полоса прогресса пересчитываются сами. Размер первого тарифа задаёт `SEATS_TOTAL` (50).

## Как поменять ссылку на оплату

В `script.js`:

```js
const PAYMENT_URL = 'https://...';
```

Ссылка подставится в главную кнопку финального блока (`data-pay`) и откроется в новой вкладке. Пока значение пустое, кнопка ведёт к блоку `#cta`.
Кнопки в шапке и hero скроллят к финальному блоку. Если они тоже должны сразу вести на оплату, добавьте им атрибут `data-pay`.
