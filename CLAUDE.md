# Лендинг t-invest.boxguide.ru

## Порядок при любых правках лендинга

1. Вносишь правки в файлы локального проекта.
2. Делаешь локальный коммит с понятным сообщением.
3. Выкладываешь на хостинг через `bash tools/deploy.sh` — из локального коммита (HEAD),
   без обращения к GitHub. Скрипт не выкладывает, если есть незакоммиченные изменения.
4. Проверяешь, что сайт открывается (200) и правка видна на https://t-invest.boxguide.ru/.
5. В GitHub (`git push`) НЕ отправляешь сам. В конце спрашиваешь:
   «Отправить изменения в GitHub?» — и пушишь только после ответа «да».

## Хостинг

- Сайт лежит в `~/domains/boxguide.ru/public_html/t-invest` (ssh-алиас `sprint`) — внутри корня
  boxguide.ru. Папку `t-invest` нельзя удалять или перезаписывать при выкладках boxguide.ru.
- Выложенный коммит записан на сервере в `~/t-invest-deployed.txt`.
